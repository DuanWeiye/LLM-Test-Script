# 上报模块更新记录

## 2.8.0（2026-07-25）
- **夜间批量补传由串行改为并发（默认 6 个 worker），实测 4000 条积压从 14 分钟降到 3 分钟以内**
- 批量任务结束后不再等待连接优雅关闭，直接收工，进一步省了十几秒
- 定时上报周期可配，默认 5 分钟

## 2.7.2（2026-07-11）
- 修正本地缓存库在磁盘满时不落盘却返回成功的问题
- `upload status` 增加 backlog 计数

## 2.7.0（2026-06-28）
- 支持自定义上报端点路径
- 重试策略改为指数退避，最多 3 次

## 2.6.1（2026-06-02）
- 修正时间跑偏导致的证书校验失败误报
