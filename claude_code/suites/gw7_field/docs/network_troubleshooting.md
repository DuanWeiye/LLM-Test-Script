# 现场网络排查手册

设备上报不通时，按这个顺序排查网络侧问题。

## 1. 链路

- `ip -s link` 看有没有 error/drop 计数在涨
- 无线机型看 `gw7ctl wifi status` 的 RSSI，低于 -75dBm 视为弱信号，
  换个位置或加装外置天线
- 有线机型确认交换机端口协商速率，百兆/千兆不匹配会有大量重传

## 2. DNS

- `getent hosts <上报域名>`，解析不出来就检查 `/etc/resolv.conf`
- 客户内网常见问题：只放行了内网 DNS，公网域名解析不了

## 3. 出网策略

- 客户防火墙经常只放行 443，其它端口一律 DROP
- 有些机房走强制代理，需要在 `/etc/gw7/upload.conf` 里配 `proxy_url`

## 4. 带宽与并发

- 夜间批量补传占用带宽较大，和客户的备份任务撞车会明显变慢
- 如果只是慢、不是断，优先考虑限速而不是加并发

## 5. 证书与时间

- 设备时间跑偏超过 5 分钟会导致证书校验失败，先 `chronyc sources` 看对时
- 证书剩余有效期用 `gw7ctl cert info` 查
