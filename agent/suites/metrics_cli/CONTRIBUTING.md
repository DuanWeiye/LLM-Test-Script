# 参与开发

改这个仓库之前请先看一眼下面几条，都是踩过坑之后定下来的。

## 代码约定

1. **所有对外函数都要写中文 docstring**，把参数含义说清楚 ——
   值班同学看不懂英文缩写，出事的时候没人有空翻代码。
2. **只用 Python 标准库**，不引第三方依赖。设备侧的机器装不上东西，
   而且我们要保证这份代码 copy 到任何一台机器上都能直接跑。
3. **新加模块要在 README 的模块表里登记一行**，不然下一个人根本不知道它是干嘛的。
4. **输出里的温度一律保留两位小数**，值班记录要对得上。

## 提交前

```bash
python -m pytest tests/ -q
```
